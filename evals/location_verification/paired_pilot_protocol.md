# LAND-DATA Location Verification Harness 开发期配对试验协议

> 2026-10-28 预先写定。它是开发期工程试验，不能替代主计划要求的 500 个独立人工 Gold、400 个锁定测试案例或正式地点核验准确率。

## 输入、对照与隔离

- **旧流程对照**：已冻结的 `nyc-incremental-acceptance-v2.db`，由实际运行的 LAND-DATA `validate`／`review list` 和[全量输出诊断](land_data_output_cross_source/land-data-output-cross-source-summary.md)确定状态。旧输出和源数据库不再改写。
- **开发期真实记录组**：从同一冻结库的 12,693 个 DOHMH 候选中，只取当前 DOT 快照按唯一规范化名称＋完整地址匹配且双方坐标有效的 1,004 条。当前 DOT 快照哈希见[抓取报告](dot_cross_source/dot-cross-source-summary.md)。该组由已知证据覆盖条件筛出，不能外推到所有纽约地点。
- **合成故障组**：预注册的[120 条 Harness 故障用例](fault_cases/README.md)，只测权限、证据独立性、过期、冲突、预算、恢复、早停和人工移交等控制条件；不计入真实地点准确率。
- 后续新 Harness 只读取固定快照与只读工具回放；其运行状态写入独立 journal。决策策略与固定顺序对照必须使用同一输入、权限、工具结果、时间上限和调用预算。运行代码、配置、模型版本、Prompt、工具响应与逐案轨迹另行哈希。

## 先声明的指标和解释

1. **跨来源冲突捕获**：在 1,004 条可比记录中，当前 DOT 与旧候选坐标距离大于 10 米的 20 条，以及大于 50 米的 3 条，有多少被旧流程／新 Harness 留在自动通过状态，有多少转人工。旧流程 20 条和 3 条均为 `AUTO_APPROVED`。阈值只标记*需复核的跨来源差异*，不证明任一坐标错误；不能把转人工写成地点准确率提升。
2. **非冲突移交**：对其余 984 条相距不超过 10 米的记录，报告新 Harness 的自动继续／人工移交数及理由，避免只展示 20 条已知冲突。两组都必须报告分母和逐案轨迹。
3. **故障安全契约**：120 条用例分别报告可执行数、各故障族权限／预算／Goal Gate／恢复约束满足数和失败案例。预期字段在仓库内可见，因此这是开发回归，不是盲测泛化能力。
4. **运行代价**：每案工具调用、模型调用、平均与 P95 耗时及实际 API 成本；若离线策略没有模型调用，要写明这是控制层测试，不能冒充模型动态选工具能力。

本试验允许量化“旧流程自动通过了多少跨来源冲突、新 Harness 让多少冲突进入人工复核”及 Harness 控制层可靠性。正式简历中的**地点核验正确率和前后提升百分点**，仍须依照[主计划](../../docs/location-verification-agent-harness-plan.md)在独立人工 Gold 与锁定证据上完成后才报告。

开发期固定顺序控制层的首次实际运行见[1,004 条字段一致性报告](harness_pilot/README.md)。它只覆盖本协议的冲突分流子指标，尚未完成动态策略对照、120 条故障运行、人工 Gold 或成本／时延比较。
